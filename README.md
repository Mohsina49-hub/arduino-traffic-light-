
# Arduino Traffic Light System 🚦

## About
This is a beginner-level electronics project built using an Arduino Uno.
It simulates a basic traffic light sequence using three LEDs.

## Objectives
- Understand Arduino digital output pins.
- Learn to control LEDs using C++.
- Practice circuit connections and basic timing.
- Combine hardware and programming.

## Components
- Arduino Uno
- Breadboard
- Red, yellow, and green LEDs
- Current-limiting resistors
- Jumper wires
- USB cable for programming and power

## Working Principle
The Arduino controls the LEDs through digital output pins.
The program switches the LEDs in a predefined sequence,
using delays to control how long each state remains active.
